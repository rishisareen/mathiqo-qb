# Length, perimeter and area, Classes 2-6:
#
# Class 2, Maths (Joyful Mathematics): compares lengths directly and
# measures using non-standard units (handspans, paces).
# Class 3, Maths (Maths Mela): measures length using standard units
# (centimetre, metre) with a ruler or tape.
# Class 4, Maths (Maths Mela), Ch. 6 (Measuring Length): measures and
# estimates lengths in centimetres, metres and kilometres; converts
# between centimetres and metres in simple cases.
# Class 5, Maths (Maths Mela): finds the length of the boundary of simple
# shapes by adding side lengths; compares the space covered by flat shapes
# by counting unit squares on a grid (e.g. quilt and tiling activities).
# Class 6, Maths (Ganita Prakash), Ch. 6 (Perimeter and Area): understands
# perimeter as the length of the boundary of a closed figure and computes
# it for polygons, using formulas for rectangles and squares; understands
# area as the region enclosed, measured in unit squares; computes areas of
# rectangles and squares using the length x breadth formula, including
# figures made of several rectangles; finds the area of a triangle as half
# of a surrounding rectangle; solves real-life problems on fencing,
# flooring and tiling.
