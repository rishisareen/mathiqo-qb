# Patterns and number sequences, Classes 1-6:
#
# Class 1-2, Maths (Joyful Mathematics): recognises, extends and creates
# simple repeating patterns of shapes, colours and numbers.
# Class 3, Maths (Maths Mela): sorts numbers as odd or even by pairing
# objects; extends number patterns based on skip counting.
# Class 4, Maths (Maths Mela), Ch. 3 (Pattern Around Us): identifies the
# rule of a pattern and extends growing patterns of shapes and numbers.
# Class 5, Maths (Maths Mela), Ch. 7 (Shapes and Patterns): extends and
# describes growing and reducing patterns; relates patterns in shapes to
# patterns in numbers.
# Class 6, Maths (Ganita Prakash), Ch. 1 (Patterns in Mathematics): studies
# number sequences — counting numbers, odd numbers, even numbers, triangular
# numbers, square numbers, cube numbers and Virahanka (Fibonacci-style)
# numbers; relates number sequences to pictorial arrangements (e.g. dots in
# triangles and squares) and explains why the patterns continue; explores
# patterns in sums (e.g. sums of consecutive odd numbers giving squares).
