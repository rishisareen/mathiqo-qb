# Fractions ladder, Classes 4-7 (new NCERT series):
#
# Class 4, Maths (Maths Mela), Ch. 5 (Sharing and Measuring): understands
# halves, quarters and other unit fractions as equal shares of a whole and
# of a collection; identifies the fraction of a shape that is shaded.
# Class 5, Maths (Maths Mela), Ch. 2 (Fractions): represents fractions of
# shapes and collections; recognises simple equivalent fractions using
# pictures; compares simple fractions; adds and subtracts fractions with
# the same denominator using pictures.
# Class 6, Maths (Ganita Prakash), Ch. 7 (Fractions): understands fractions
# as equal shares and as fractional units; places and reads fractions on
# the number line; expresses improper fractions as mixed numbers and vice
# versa; generates and recognises equivalent fractions; expresses a
# fraction in lowest form; compares and orders fractions; adds and
# subtracts fractions with like and unlike denominators using equivalent
# fractions (Brahmagupta's method).
# Class 7, Maths (Ganita Prakash), Ch. (Working with Fractions): multiplies
# a fraction by a whole number and by another fraction, connecting
# multiplication to area and "of" language; divides a fraction by a whole
# number and by another fraction; expresses results in lowest form.
