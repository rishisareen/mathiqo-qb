# Data handling, Classes 3-6:
#
# Class 3, Maths (Maths Mela): collects simple data from the class and
# records it using marks or pictures; answers questions from the record.
# Class 4, Maths (Maths Mela), Ch. 10 (Elephants, Tigers and Leopards):
# records data using tally marks; reads and draws pictographs where one
# symbol stands for several units; answers questions by reading tables and
# pictographs.
# Class 6, Maths (Ganita Prakash), Ch. 4 (Data Handling and Presentation):
# collects and organises data using tally marks and frequency tables; reads
# and draws pictographs with a scale; reads and draws bar graphs, choosing
# an appropriate scale; interprets and compares data presented in tables,
# pictographs and bar graphs.
