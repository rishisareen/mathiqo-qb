# Whole-number arithmetic ladder, Classes 1-6:
#
# Class 1, Maths (Joyful Mathematics): counts collections of objects; reads
# and writes numerals up to 99; compares small numbers using more/less.
# Class 2, Maths (Joyful Mathematics): understands place value of tens and
# ones; compares and orders two-digit numbers; adds and subtracts two-digit
# numbers without and with simple regrouping.
# Class 3, Maths (Maths Mela): reads, writes, compares and orders numbers up
# to 999 using place value of hundreds, tens and ones; adds and subtracts
# three-digit numbers with regrouping; recalls multiplication facts for
# tables of 2, 3, 4, 5 and 10; understands multiplication as repeated
# addition and division as equal sharing.
# Class 4, Maths (Maths Mela), Ch. 4 (Thousands Around Us): reads, writes,
# compares and orders numbers up to 10,000 using place value; expresses
# numbers in expanded form.
# Class 4, Maths (Maths Mela), Ch. 9 (Equal Groups): recalls multiplication
# facts up to 10 x 10; multiplies two-digit numbers by one-digit numbers;
# divides with remainders using equal grouping and sharing.
# Class 5, Maths (Maths Mela): reads and writes large numbers using Indian
# place-value grouping (up to lakh); adds, subtracts, multiplies and divides
# larger whole numbers; rounds numbers and estimates the results of
# operations before computing.
# Class 6, Maths (Ganita Prakash), Ch. 3 (Number Play): revisits place value
# through digit games and puzzles (digit sums, palindromic numbers, number
# patterns such as the Kaprekar routine); estimates quantities and results
# of operations, judging the reasonableness of an answer; arranges digits to
# make numbers satisfying given conditions.
